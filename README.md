# 3D Shop Simulator
3D 상점 환경에서 상품 구매, 진열, 고객 응대, 계산, 하루 정산, 저장/불러오기를 구현한 1인칭 상점 운영 시뮬레이터입니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 3D Shop Simulator |
| 장르 | 3D 상점 운영 시뮬레이터 |
| 개발 엔진 | Unity 6 |
| 개발 언어 | C# |
| 개발 인원 | 1인 개발 |
| 개발 목적 | 클라이언트 개발자 포트폴리오용 개인 프로젝트 |

## 주요 기능

### 상점 운영
- 상품 구매
- 상품을 플레이어 손에 들기
- 진열대에 상품 배치
- 하루 종료 및 정산 시스템

### 고객 및 계산 시스템
- 고객 AI를 통한 상품 선택
- 고객의 계산대 이동
- 계산대 처리 및 매출 반영
- 미결제 상품 반납함 시스템

### 저장 및 옵션
- JSON 기반 저장/불러오기
- 메인 메뉴 및 인게임 오디오 설정
- 일시정지 메뉴

## 조작 방법

| 조작 | 기능 |
|---|---|
| WASD | 이동 |
| Mouse | 시점 조작 |
| E | 상호작용 |
| ESC | 일시정지 메뉴 |
