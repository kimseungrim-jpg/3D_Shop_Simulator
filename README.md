# 3D Shop Simulator
3D 상점 환경에서 상품 구매, 진열, 고객 응대, 계산, 하루 정산, 저장/불러오기를 구현한 1인칭 상점 운영 시뮬레이터입니다.  
플레이어는 상점 주인이 되어 상품을 구매하고 진열대에 배치하며, 고객이 선택한 상품을 계산합니다.  
하루가 종료되면 아이템 구매에 사용한 비용과 판매 금액을 정산하고, 저장/불러오기 기능을 통해 상태를 이어갈 수 있습니다.

## 주요 기능

### 상점 운영
- 상품 구매
- 상품을 플레이어 손에 들기
- 진열대에 상품 배치
- 하루 종료 및 정산 시스템

### 고객 AI 및 계산 시스템
- 고객 AI 상점 입장
- 진열된 상품 선택
- 계산대로 이동
- 계산 완료 시 매출 반영
- 미결제 또는 대기열 이탈 시 상품 반납 후 퇴장

### 저장 및 복원 시스템
- JSON 기반 저장/불러오기
- 날짜, 보유 금액, 매출 정보 저장
- 진열대 상품 상태 저장
- 바닥 재고 아이템 저장
- 플레이어가 들고 있는 아이템 저장
- 반납함 아이템 저장

### UI 및 옵션 시스템
- 메인 메뉴
- 이어하기 기능
- 일시정지 메뉴
- 메인 메뉴 및 인게임 오디오 설정
- BGM/SFX 음량 조절 및 저장

## 조작 방법

| 조작 | 기능 |
|---|---|
| WASD | 이동 |
| Mouse | 시점 조작 |
| E | 상호작용 |
| ESC | 일시정지 메뉴 |
